# Issue Report Template

## Purpose
Generate a structured security issue report from analyst outputs. Suitable for developer consumption and issue tracker integration.

## Sections
- Title and severity badge
- Vulnerability summary (1-2 sentences)
- Root cause with code reference
- Reproduction steps (from minimized artifact)
- Impact assessment
- Remediation guidance
- Regression test (from harness)

## Output Format
Markdown with embedded code blocks. Designed for GitHub Issues / Jira integration.

## Notes
Reports are the primary user-facing output of a campaign. Quality directly impacts user trust.
