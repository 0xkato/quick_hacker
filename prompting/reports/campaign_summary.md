# Campaign Summary Report

## Purpose
Generate an executive summary of a completed campaign. Aggregates lane results, issue counts, coverage metrics, and time spent.

## Sections
- Campaign overview (targets, lanes, runtime)
- Issues found by severity
- Coverage achieved per target
- Methodology effectiveness comparison
- Steering decisions and their outcomes
- Recommendations for follow-up campaigns

## Output Format
Markdown dashboard with inline metrics. Designed for security team review.

## Notes
Includes a "diminishing returns" analysis: which lanes were most productive and where additional budget would help.
